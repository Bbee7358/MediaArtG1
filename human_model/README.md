# Rigged human model

The visible figure uses the rigged `Superhero_Female_FullBody.gltf` base mesh
from Quaternius' **Universal Base Characters** pack. Its original textures are
loaded only for glTF compatibility and are replaced at runtime with a single
neutral, translucent sculptural material. Eyebrows and hair are not rendered,
removing character-specific styling.

The model's 65-bone humanoid rig is set once to a neutral standing pose and is
then kept completely static. Brain-area selection does not animate the bones,
play a character clip, or replace the model with video. The former CSS outline
fallback is permanently hidden, so a failed or pending model load shows no
low-quality substitute figure.
