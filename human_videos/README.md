Put replacement human-motion videos here.

- `walk.mp4` for the default motion
- `visual.mp4` for visual-node motion
- `auditory.mp4` for auditory-node motion
- `gustatory.mp4` for gustatory-node motion
- `memory.mp4` for hippocampus-node motion
- `amygdala.mp4` for amygdala-node motion

Use transparent or black-background videos if possible. Missing files fall back to the built-in placeholder silhouette.
